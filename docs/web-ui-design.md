# AutoBench Web UI 设计

2026-11-03，使用 Taste Skill 的应用界面流程重构，保留 FastAPI、原生 ES modules 和 CSS。

## 方向

采用 **Framed sheet**，seed `1126914164`，没有重抽设计方向。灰绿色导航与顶栏组成框架，白色工作区向右、向下各留 8px，使用 16px 圆角与轻边框，不使用面板阴影。沿用 AutoBench 的绿色作为品牌和状态色。

IBM Plex Sans 用于界面，IBM Plex Mono 仅用于文件路径、配置标识、启动项和源码。四个字体文件及其 SIL Open Font License 均随 Python 包分发，无需运行时访问字体服务。

产品辨识元素是配置向导中的实时测试计划：机器下面按配置顺序列出 UEFI 系统及启动项，再列出测试和轮次。任务数与最终检查页共同使用现有 `counts()`，修改配置立即更新，不生成额外 YAML 字段。

## 数据与使用场景

面向编排跨系统性能测试的开发者，桌面完成配置，手机查看进度与恢复操作。现有数据对象包括：

- 机器：标识、SSH 地址、端口、用户名、认证方式。
- 操作系统：标识、UEFI 启动项、继承与覆盖的连接参数。
- UnixBench：源码包、测试项、命令参数、环境变量。
- 执行轮次：每项测试的重复次数，以及系统与测试组合产生的任务数。
- 调度策略：并行机器数、等待时间与连接超时。
- 配置文件：路径、版本、草稿与保存状态。
- 环境检查：连接、启动项、运行依赖、磁盘空间。
- 运行记录：创建时间、状态、更新时间、控制器连接情况。
- 任务与事件：机器和系统分组、当前阶段、失败原因、原始日志。
- 结果产物：文件路径、大小、预览、单文件下载与归档下载。

## 各页面首先回答的问题

| 页面     | 首先回答                                     | 主要操作                                     |
| -------- | -------------------------------------------- | -------------------------------------------- |
| 测试配置 | 哪些机器与系统将执行哪些测试，一共多少任务？ | 填写连接、选择系统、设置测试、保存并检查     |
| 环境检查 | 当前系统是否具备运行条件？                   | 选择目标机器，检查当前环境，定位需处理的项目 |
| 运行记录 | 哪次测试需要关注，能否继续或取回结果？       | 查看详情、恢复控制、继续取消、收集与下载结果 |

向导编号仅表示配置顺序，不能视为配置已通过校验。只有后端验证通过后，才显示检查通过状态与开始测试操作。

## 布局与状态

1440px 宽度下：`1440 − 228 导航 − 8 外边距 − 64 内边距 − 2 边框 = 1138`，配置列 `834 + 24 间隔 + 280 预览 = 1138`。完整工作台保留机器与配置区域导航，不叠加第三列预览。

1100px 以下折叠为顶部导航，850px 以下配置与计划堆叠，600px 以下增大表单控件与操作触点。手机上的运行记录为双行列表，创建时间、运行标识、状态、更新时间和详情操作均可见，无需横向滚动。

状态通过文字与 SVG 标记共同表达。数字列右对齐并使用等宽数字；空值不伪造数据。补充了当前页面、当前步骤、编辑模式和字段说明的无障碍属性，以及键盘跳转到主要内容的入口。切换主页面后回到页面顶部。

## 视觉验证

使用实际 Chromium 在 1440、768、390px 检查。除首屏前后对比外，还截图复查四步配置、完整工作台、环境检查与运行记录，共 21 个组合；全部无页面横向溢出和 JavaScript 异常。

| 指标                 | 重构前 | 重构后 |
| -------------------- | ------ | ------ |
| 标题字号（桌面）     | 29px   | 22px   |
| 首屏使用的字号数     | 12     | 6      |
| 最小文字字号         | 7px    | 12px   |
| 浏览器检查 FAIL 类别 | 4      | 0      |
| 浏览器检查 WARN 类别 | 3      | 1      |
| 源码风格检查 FAIL    | 3      | 0      |

重构前的 4 项 FAIL 中，1 项来自与新方向的字体对比；其余为按钮效果、过重阴影和过小字号。重构后的字号提示保留：路径、版本、辅助说明与状态元信息为 12px，表单标签与主要操作为 13–14px，不以放大所有元信息代替层级设计。

源码检查保留的提示均有实际用途：已有配置标识使用补零；等宽字体用于标识、路径和代码；阴影仅用于文件菜单、模态框和预览抽屉。未使用检查豁免参数。

截图复查后修正的三处问题：手机运行记录的详情操作移出横向滚动区域；配置向导不再以勾号暗示前面步骤已经校验；主要配置与计划文字增大到 13px。最终第一屏以连接表单与测试任务范围为中心，颜色用于状态，内容与工作区边缘对齐。
